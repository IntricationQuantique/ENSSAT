# Interfacing

The aim of this project is to implement current control of a laser diode.
The system will consist of an ATxMEGA128A1 microcontroller board responsible for controlling the
laser diode. It must allow the current flowing through the diode to be selected and
measured. The microcontroller board will be connected to a PC on which a
command-line interface (Putty Terminal) will be used to send commands to the system.
